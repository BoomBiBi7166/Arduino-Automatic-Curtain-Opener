# Arduino-Automatic-Curtain-Opener
An automatic curtain opener (CSS332 project)

## Langauge
- C++

## Component
- Arduino Servo MG996R
- Arduino Real Time Clock Module DS3231
- 5V 4A Adapter

## Note
You can change the opening/closing time in line 34 and 39.
